# 一棵柠檬树 | The Lemon Tree🌲

**一棵会“听”你朗读阿拉伯语童话的互动数字绘本。文字从屏幕轻轻剥落，落入泥土，化作养分；雨、光、风、花、蜂与果，都随着你的声音自然苏醒。**

---

## 项目简介

“言灵之树”是一个基于 Web Speech API 和 HTML5 Canvas 的交互式数字绘本网页。用户通过朗读屏幕上的阿拉伯语童话文本，驱动一棵柠檬树从种子逐渐生长为枝繁叶茂、开花结果的完整生命历程。

本项目是学士学位论文《生成式人工智能在阿拉伯语写作课程学习中的应用研究》的实践案例之一，旨在展示如何利用 DeepSeek 等大语言模型，通过提示词工程将语言学习需求转化为可交互的数字产品。

**在线体验地址**：https://assia-lemon-tree.netlify.app

---

## 核心特性

- **语音驱动交互**：使用 Web Speech API 实时监听用户朗读，匹配阿拉伯语文本并触发文字剥落
- **阶段化叙事演出**：全文划分为 8 个语义阶段，场景随朗读进度自然切换——种子、夏雨、阳光、破土、枝叶、开花、蜜蜂、结果
- **有机生长动画**：所有动画基于二次贝塞尔曲线和 Math.sin(time) 流体扰动，拒绝生硬直线和突然闪现
- **多语言/多版本支持**：提供阿拉伯语（标准版 / 带发音符号版）、中文、英文三种语言体验
- **双轨交互驱动**：语音识别为主，鼠标划过文本为辅助降级方案，确保交互流畅
- **触摸擦除与蝴蝶跟随**：结尾阶段可触摸树干，树枝化作蝴蝶追随鼠标飞舞，完成首尾呼应的诗意收束

---

## 技术栈

- **HTML5 Canvas**：所有视觉元素的绘制与动画
- **Web Speech API**：阿拉伯语语音实时识别
- **JavaScript (原生)**：物理粒子系统、贝塞尔曲线生成、多维状态机、Lerp 平滑插值
- **CSS3**：极简排版、过渡动画
- **Google Fonts (Amiri)**：阿拉伯语优雅衬线字体

**无任何外部框架或打包工具依赖，所有样式和脚本内联在单个 index.html 文件中。**

## 如何使用

### 在线体验
直接访问 [https://assia-lemon-tree.netlify.app](https://assia-lemon-tree.netlify.app)，授予麦克风权限后即可开始朗读。

### 本地运行
1. 下载项目中的 `index.html` 文件
2. 使用 Chrome 或 Edge 浏览器打开（需支持 Web Speech API）
3. 授予麦克风权限
4. 点击“唤醒文字”按钮，开始朗读屏幕上的童话文本

---

## 使用提示和注意事项

### 浏览器兼容性
- **推荐**：Chrome 桌面版、Edge 桌面版（对 Web Speech API 支持最佳）
- **不支持**：Firefox（部分语音识别功能受限）、Safari（需手动授权）
- 移动端浏览器可能存在语音识别的稳定性差异

### 朗读小贴士
- 以自然、流畅的速度朗读，无需刻意放慢
- 如果某个单词识别卡顿，可以用鼠标划过该词作为辅助
- 阿拉伯语发音符号（Tashkeel）不会影响识别，系统会自动剥离
- 如果长时间未朗读，语音识别可能自动暂停，刷新页面即可

### 语言切换
- 启动页面提供阿拉伯语标准版和带发音符号版两种选择
- 朗读完所有文本并完成结尾交互后，会出现其他语言版本的体验选项

## 开发背景与过程

本项目由阿拉伯语专业本科生独立构思，所有代码（约 1200 行）均由 **DeepSeek** 基于自然语言提示词生成。开发过程历时约三天，经历了多轮与 AI 的对话迭代：

1. **第一轮**：使用基础提示词生成网页核心框架——文本剥落、粒子掉落、基础树木生长
2. **第二轮**：优化排版（缩小字号、增加留白）、提升阿拉伯语语音识别鲁棒性（字符归一化、滑动容错窗口）
3. **第三轮**：构建阶段化叙事系统——将全文划分为 8 个语义阶段，增加天气、光照、蜜蜂等环境元素，所有状态切换通过多维状态机和 Lerp 插值实现平滑过渡
4. **第四轮**：增加带发音符号的阿拉伯语版本、中文和英文版本，实现语言切换与性能优化

**核心经验**：一次性输入完整提示词无法直接生成最终成品。有效的开发策略是“先框架、后细节、逐步迭代”，每一轮只让 AI 聚焦解决一个问题，并将修改后的代码片段交由 StepClaw 等 AI 助手进行增量更新，而非每次都要求 AI 重新生成整个文件。
